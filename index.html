Garmin Training Hub

A personal project for collecting and reviewing the owner's own Garmin activity and wellness data.

Purpose

The application is designed to synchronise Garmin data to the owner's private Google Drive and Google Sheets for personal training analysis.

Google account access

Google authorisation is used to create and manage the files used by this application. The application requests the limited drive.file permission, rather than access to the entire Google Drive.

This public website contains information about the project. It does not display training records, health data, API keys or access tokens.

Privacy policy
